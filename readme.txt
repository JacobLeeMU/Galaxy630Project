The code in this repository was written in order to test the performance of the large multimodal model (LMM) LLaVA on analyzing a subset of galaxy images from the Galaxy10 DECaLS dataset. We aim to compare the output produced through single-step prompting with an agentic workflow. 

For instructions on how to run our code, please see the file: CS630_Project_Setup_Instructions.pdf included with our submission. 

Here is a brief summary of the files contained in this repository: 

final_project.py - this is the program that implements the LLaVA workflow. 

results.txt - this is sample output that was generated by running final_project.py

makeSubset.py - this program was used to create a 15-image subset from the larger Galaxy10 dataset, as well as create a plot of our selected images for use in our report and poster. (Note that the larger dataset that we pulled from in this script can be downloaded here: https://astronn.readthedocs.io/en/latest/galaxy10.html#download-galaxy10-decals)

galaxy_sample15.h5 - this is the subset of the Galaxy10 DECaLS dataset that we used in this project. 

The "Figures" directory contains the galaxy image grid created using makeSubset.py.
